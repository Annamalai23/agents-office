2. Add to the table above
3. If the client signed a proposal, link to `60-Sales/proposals/YYYY-MM-DD-client-name.md`
4. If the client has a project, link to `70-Delivery/projects/YYYY-MM-DD-project-name.md`
5. Hand off to ONBOARDER (ona) for onboarding
