# QA checklist

> Used by QA CHECKER (qa). Read before every client handover.

## Checklist

### Links & Assets
- [ ] All URLs return HTTP 200 (no 404s)
- [ ] All images load (no broken image icons)
- [ ] All downloads (PDFs, assets) are the latest version
- [ ] Form submissions work (test with dummy data)
- [ ] Phone numbers and email addresses are correct

### Copy & Content
- [ ] No spelling errors (run spell check)
- [ ] No grammar errors (read aloud)
- [ ] Tone matches brand voice ([[voice]]) — plain, warm, specific
- [ ] No jargon, no hype
- [ ] All claims are sourced or marked "estimated"

### Brand
- [ ] Colours match [[visual-identity]] palette
- [ ] Fonts are correct (headings + body)
- [ ] Logo placement is correct and not distorted
- [ ] Spacing and layout follow brand guidelines

### Numbers & Accuracy
- [ ] Every metric traces to [[numbers-ledger]] or client data
- [ ] All prices match [[offer-ladder]]
- [ ] Dates and timelines are consistent
- [ ] Contact details are current

### User Experience
- [ ] Mobile-responsive (test on 3 screen sizes)
- [ ] Page load < 3 seconds
- [ ] The three things a client do first are obvious
- [ ] Exit intent / next step is clear

### Client-Specific
- [ ] Client feedback from review round is addressed
- [ ] Any requested changes are implemented
- [ ] Final deliverable matches the scope signed off in the proposal

## Sign-off
- All checks pass → "Verified ✓ — [date]"
- Any blocker → "QA FAIL: [issue]" — send back to responsible agent

Nothing ships without a pass.
