# Explorer's Lab — AI Brain

This folder is the learning brain: the notes the agents read before they act and write to when they finish.
This office is set up for exploration and knowledge-building. Read `00-Meta/index.md` first, then the
MOC for the department your task touches.

The active learning system lives in `90-Knowledge/`: the Codex (rules, tokens, badges), the Quest Board,
Progress, Achievements, and the Research/Digests/Insights folders where notes land.

Rules
- Numbers and token counts come from `90-Knowledge/` only. Never invent a figure or a token award.
- Every research note ends with three quest seeds so learning compounds.
- Nothing posts outbound (social, email, publishing) without the owner's approval.
- This folder is backed up to Git so the team shares one brain.
